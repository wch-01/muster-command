# Contributing

Muster Command is open source, but the official project is currently developed and maintained exclusively by Web Craft House.

## Welcome

- Bug reports
- Reproducible issue reports
- Feature suggestions
- Usability feedback
- Security reports submitted through the process described in [SECURITY.md](SECURITY.md)

## Not Currently Accepted

- Unsolicited pull requests
- Third-party code contributions
- Large refactors or alternate implementations submitted for inclusion in the official project

Opening the source code does not imply that outside code contributions will be accepted into the official Muster Command repository.

If a pull request is submitted without prior invitation, it may be closed without review.

Users are free to fork and modify Muster Command according to the terms of the GNU Affero General Public License v3.0 (`AGPL-3.0-only`).
