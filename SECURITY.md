# Security Policy

## Supported versions

Security fixes are applied to the latest release and the current default branch. Older releases may not receive patches.

## Report a vulnerability privately

Do not open a public GitHub issue for a suspected vulnerability.

Email [contact@webcrafthouse.com](mailto:contact@webcrafthouse.com) with the subject `Muster Command security report`. Include a concise description, affected version or commit, reproduction details, potential impact, and any suggested mitigation. Remove real Discord tokens, OAuth secrets, personal data, and production database contents from the report wherever possible.

Please allow time to investigate before publicly disclosing the issue. Web Craft House may ask for additional information or coordinate a disclosure timeline after confirming the report.

For ordinary bugs and feature requests that do not have a security impact, use the public repository issue templates.
