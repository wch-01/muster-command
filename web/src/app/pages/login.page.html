Setup required before login

Muster Command cannot use Discord login until its Discord application credentials are supplied. System Admin is protected by this login, so complete these bootstrap steps on the server first.

Missing configuration {{ setting }}
  1. Open the Discord Developer Portal and create or select the Muster Command application.
  2. Copy General Information → Application ID.
  3. Open OAuth2 → General, copy the Client Secret, and add this redirect URL:{{ redirectUrl || "https://your-domain.example/auth/discord/callback" }}
  4. Open Bot, create/reset and copy the bot token, and enable Server Members Intent.
  5. Copy your own Discord user ID for the initial System Administrator. Discord Developer Mode exposes Copy User ID in your profile context menu.
  6. Create an environment file beside compose.yml and add:
APPLICATION_ID=your_application_id
DISCORD_CLIENT_SECRET=your_client_secret
DISCORD_BOT_TOKEN=your_bot_token
ADMIN_DISCORD_USER_IDS=your_discord_user_id
STATE=production

Keep the bot token and client secret private. Do not paste them into Discord or commit the environment file to Git.

Restart the deployment after saving the file:

docker compose --env-file .env up --build -d

Reload this page and choose Continue with Discord. After login, use System Admin to confirm the public website URL and register the /mc commands.
