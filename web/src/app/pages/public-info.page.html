About Muster Command

Muster Command helps Discord communities organize events, fleet and ground-team assignments, attendance, and participant loot drawings from a shared website and Discord bot.

What it provides

  • Structured event creation and reusable templates
  • Discord and website signup controls
  • Schedule-aware fleet and ground-team assignments
  • Participant-only loot pools and drawings
  • Per-server administration and Discord command-access tiers

Muster Command is built by Web Craft House as part of its games, community tools, and interactive experiences work. It is independently operated and is not affiliated with Discord or Cloud Imperium Games.

Privacy

Muster Command uses Discord OAuth to identify users and determine which Discord servers they share with the bot. The application requests the identify and guilds OAuth scopes.

Information handled

  • Discord user ID, username, display name, and avatar reference
  • Discord server IDs and names needed to select a shared server
  • Server nickname and role membership when needed for profiles and permissions
  • Event assignments, loot entries, bids, and results created through Muster Command

How it is used

This information is used only to authenticate users, enforce server and event permissions, display participation, and operate event and loot features. Discord credentials used to run a self-hosted instance are supplied by that instance's operator.

Storage and control

Each deployment stores its own event data and settings. The operator of that deployment controls retention, backups, and access. Signing out removes the browser session cookie; it does not delete event history or records needed by the server community.

Questions or removal requests

Contact the operator of the Muster Command instance first. For this project, contact contact@webcrafthouse.com.

Help and Getting Started

Joining an existing community

  1. Log in with Discord.
  2. Select a server that already has Muster Command installed.
  3. Open Events to join an available role or view its loot pool.

Adding Muster Command to a server

After login, use the visible Add to Server button in the header. Discord only offers servers where your account has permission to install or manage applications.

Running your own deployment

If the login page reports missing configuration, follow its bootstrap instructions. After login, System Admin lets the operator confirm the public website address and register Discord commands.

For further help, visit Web Craft House support.
